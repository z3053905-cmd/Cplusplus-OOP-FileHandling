# 🚗 Automobile Management System (C++ OOP & File Handling)

A lightweight C++ console application that demonstrates the practical use of Object-Oriented Programming (OOP) core concepts, Array of Objects, File I/O operations, and basic Pointer utilization.

## 🛠️ Features Implemented
* **Inheritance & Polymorphism:** Created a base class `car` and derived class `sportscar` to implement class hierarchy and constructor chaining.
* **Code Optimization:** Leveraged an **Array of Objects** combined with a `for` loop to eliminate code redundancy (DRY principle) while writing data.
* **File Handling (Persistence):** Automates saving vehicle specifications into a local structured text file (`car.txt`).
* **Memory Management:** Includes a demonstration of memory addresses and value access using raw **Pointers**.

## 💻 Tech Stack
* **Language:** C++ (C++11 or higher)
* **Concepts:** OOP, Stream I/O (`fstream`), Pointers, Arrays
